# Documentation Artifacts

This directory contains the presentation and architecture documents required for the Happiest Health Summit 2026 submission:

1. `Architecture_Diagram.pdf` (or `.ppt`) — System architecture and dual-stream data fusion pipeline diagram.
2. `Presentation.pdf` (or `.ppt`) — Project slide deck covering clinical problem statement, Indian T2D use case, AI/ML model methodology, empirical validation, and outcomes.

Ensure your exported PDF/PPT files are placed here and committed to the repository so they are publicly accessible to the evaluation panel.
